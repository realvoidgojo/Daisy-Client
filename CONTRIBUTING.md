# Contributing to Daisy

Use the [contributor guide](docs/contributing.md) for layout, feature work and checks.
Use [building](docs/building.md) for local setup and [releasing](docs/releasing.md)
for version/tag policy. Open focused pull requests against `main` with the problem,
resulting behavior, validation results and any runtime limitations.

Preserve stored settings, exact Minecraft compatibility, resource IDs and existing
worlds. Changes to those contracts need a migration. Do not commit generated builds,
credentials or assets without provenance. Contributions to Daisy source are MIT licensed;
third-party materials must retain their own terms and notices.
